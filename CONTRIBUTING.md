# Contributing

Use [Issues](https://github.com/ardelato/ioi-puzzle-radar/issues) to report a
reproducible bug or discuss a change. Include the Puzzle Radar version and steps from
the [test checklist](docs/TESTING.md). Remove account IDs, personal paths
and tokens from excerpts before posting. Keep saves, full crash directories,
archive keys and local build inputs on your machine.

For a code change, open a pull request with the reason for the change and the
checks you ran. Keep changes focused and include tests or screenshots where they
help explain the result. The [build guide](docs/BUILDING.md) covers synthetic
tests and local asset integration.

This repo runs hosted tests after a push to `main` and when a maintainer
dispatches the workflow on `main`. Maintainers review contributor code in the
pull request and run any needed pre-merge checks in an isolated environment.
